About the EV Charging System

Engineering project report overview, architecture, and technology stack.

⚠️

Problem Statement

With rapid electric vehicle adoption, EV users frequently experience range anxiety, unpredictable queue wait times, and arrive at stations only to discover all charging guns are occupied or under maintenance. Lack of real-time reservation systems leads to grid congestion and driver frustration.

💡

Proposed Solution

This platform empowers drivers to discover charging stations via live interactive telemetry, review real-time charger bay statuses, reserve guaranteed time slots in advance, and leverage AI models to predict peak hours and identify smart station recommendations.

Technology Stack

Frontend Architecture

HTML5, Modern CSS3, JavaScript (Vanilla ES6+), Leaflet.js Interactive Maps, Chart.js Visualizations.

Backend Engine

Python 3, Flask REST API framework, Werkzeug security with PBKDF2 password hashing & session management.

Database Tier

MySQL 8.0 schema (`schema.sql`) with dual SQLite instant-execution zero-config engine.

Machine Learning

Scikit-learn, Pandas, NumPy, Joblib regression pipeline for hourly charging demand prediction.

Future Scope & Enhancements

📱 Mobile Application: Native Flutter / React Native cross-platform app.
📍 Live GPS Navigation: Turn-by-turn routing with battery state of charge (SoC).
🔌 IoT Charger Hardware: OCPP 2.0.1 smart relay integration.
💳 Online Payment Gateways: UPI, Razorpay, and wallet auto-deduction.
📸 QR-Based Quick Charging: Scan QR on port to unlock gun and start session.
🤖 Dynamic Surge Pricing: Automated electricity tariff optimization.
